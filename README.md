# Accounts & Contacts Management Application

## Overview

The Accounts & Contacts Management Application is a Salesforce-based CRM solution developed using Apex and Lightning Web Components (LWC). The application helps manage Accounts and related Contacts through dynamic Lightning components and automated Salesforce business logic.

This project was built to strengthen hands-on understanding of Salesforce CRUD operations, Apex-LWC communication, Lightning Data Service, and scalable component-based UI design.

---

## Features

* Account and Contact record management
* CRUD operations using Apex and LWC
* Lightning Datatable implementation
* Parent-child component communication
* Dynamic UI rendering
* SOQL-based data retrieval
* Apex controller integration

---

## Technologies Used

* Salesforce
* Apex
* Lightning Web Components (LWC)
* SOQL
* Lightning Data Service
* JavaScript

* CSS
